Import Data Inventaris (.xlsx)

Unggah file Microsoft Excel berisi daftar barang. Fitur ini dilengkapi **Modul Review & Validasi Baris** sebelum data di-commit ke database sistem.

Ketentuan Import Excel:
  • Gunakan format template resmi agar nama kolom sesuai.
  • Jenis barang wajib `ASSET` atau `MODAL`.
  • Jurusan wajib `TKJ`, `TKR`, `TSM`, `ATK`, `BUKU`, atau `UMUM`.

Export Excel & ZIP Archive Foto

Ekspor seluruh data inventaris ke spreadsheet Excel (.xlsx) sekaligus mengunduh paket arsip **.ZIP** terstruktur berisi foto barang, detail visual, dan `MANIFEST_SHA256.txt`.
